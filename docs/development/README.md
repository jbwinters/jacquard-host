# Development evidence

The [public examples](../../examples/README.md) are the recommended starting
point. This directory retains the experiments that informed the Python SDK.

- [Original adapter usability experiments](python-projects/README.md) record
  the 0.1.0 baseline: manual identities and values, fault cases, and boundaries.
- [SDK measurements](sdk-results.json) record one installed 0.2.0 run of
  `examples/python_sdk/exercise.py`, including source digests and timings.

Recorded machine paths have been replaced with descriptive placeholders for
publication; source digests, measured outcomes, and timings are preserved.
The reports are observations from one developer's machine, not performance
guarantees or participant-onboarding evidence. Regenerate reports under
`.scratch/` using the commands in each walkthrough.
