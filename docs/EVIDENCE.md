# Evidence

Reproducible evidence for the first host integration (roadmap H0 and H1),
recorded on 2026-09-12 against the pinned Core artifacts in
[COMPATIBILITY.md](COMPATIBILITY.md). Every number below is regenerated by the
commands in this document; nothing here is a claim beyond what those commands
show. Read [LIMITS.md](LIMITS.md) beside every statement.

## Reproduction

```sh
# offline (no Core needed): codecs, envelopes, session, registry, socket host,
# study store, the kit's recorded transcripts, and stand-in worker runs
python3 -m compileall -q src tests
PYTHONPATH=src python3 -m unittest discover -s tests -v

# live: the same suite with the real worker, the Jacquard Warp suite, the
# adapter through Core, the study operation, and the end-to-end trial
PYTHONPATH=src JACQUARD_BIN=/path/to/jacquard JACQUARD_PRELUDE=/path/to/prelude \
  python3 -m unittest discover -s tests -v

# the conformance kit replayed against the worker, with a JSON report
PYTHONPATH=src JACQUARD_BIN=/path/to/jacquard JACQUARD_PRELUDE=/path/to/prelude \
  python3 -m jacquard_host.kit --report .scratch/kit-replay.json

# the synthetic trial on loopback
PYTHONPATH=src JACQUARD_BIN=/path/to/jacquard JACQUARD_PRELUDE=/path/to/prelude \
  python3 -m jacquard_host.trial --workdir .scratch/trial --port 0
```

`JACQUARD_BIN` and `JACQUARD_PRELUDE` must come from one Core build at the
pinned commit; the worker, the prelude, and the kit identities are one unit.

## Non-claims

Each row of [LIMITS.md](LIMITS.md) is a non-claim with the condition for
removing it. In particular this evidence does not show hostile-code isolation,
a production security posture, a public network service, throughput, or any
readability result; the trial is synthetic data on loopback. The conformance
claim is "replays the pinned kit" until Core publishes the kit's evidence
pack.
